{{ _("1. Télécharger le certificat") }}

{{ _("iPhone (Safari)") }}

  1. {{ _("Touchez Autoriser quand Safari propose de télécharger un profil de configuration.") | safe }}
  2. {{ _("Ouvrez Réglages › Général › VPN et gestion de l'appareil, touchez « Bibliothèque perso », puis Installer.") | safe }}
  3. {{ _("Ouvrez Réglages › Général › Informations › Réglages des certificats (tout en bas) et activez la confiance totale pour « Bibliothèque perso ».") | safe }}

{{ _("Android (Chrome)") }}

  1. {{ _("Le fichier bibliotheque-ca.crt est téléchargé.") }}
  2. {{ _("Ouvrez Paramètres › Sécurité et confidentialité › Plus de paramètres de sécurité › Chiffrement et identifiants › Installer un certificat › Certificat CA (les intitulés varient selon les marques : cherchez « certificat » dans les Paramètres).") | safe }}
  3. {{ _("Confirmez « Installer quand même », puis choisissez le fichier téléchargé.") }}

{{ _("Avec Firefox, une étape de plus : Firefox n'utilise pas d'office les certificats installés dans Android. Ouvrez Paramètres › À propos de Firefox, touchez plusieurs fois le logo Firefox pour afficher les paramètres secrets, puis revenez dans Paramètres › Paramètres secrets et activez « Utiliser des certificats d'autorité tiers ». Plus simple : faites l'étape 2 avec Chrome.") | safe }}
